# **맞춤형 국내 여행 AI 플래너, 길동이의 꿈!**

여행 컨텐츠 분석부터 맞춤 여행 코스 생성까지, 여행 준비를 AI에게 맡겨보세요.

### 모두가 원하던 바로 그 서비스!

2025년 3월, 여행자 44명 대상 설문조사 결과:

- 71.8% 유튜브를 정보 탐색 채널로 활용
- 74.4% 여행 일정을 직접 지도에 입력해 계획
- 하지만.. 복잡하고 시간이 오래 걸린다는 피드백 다수
길동이의 꿈은 이 모든 문제를 **단 하나의 플랫폼**으로 해결합니다.

### 나만을 위한 AI 여행 메이트

- 사용자가 제공한 **여행 관련 콘텐츠**를 기반으로 주요 여행지를 분석합니다.
- AI가 나의 여행 분위기와 스타일을 파악하고, 전통시장부터 로컬 맛집까지 정성껏 안내해줍니다.

### 여행이 쉬워지는 AI 동선 설계

- 입력된 여행지를 토대로 Kakao Map, Tour API 기반의 최적 경로를 자동으로 계산합니다.
- 대중교통, 자동차, 도보 등 이동 수단에 따라 **예상 소요 시간**도 함께 알려드립니다.

### 감성까지 반영한 여행 코스 추천

- 혼자 떠나는 힐링 여행부터 친구들과의 축제 여행까지, ***나만의 여행 분위기***를 입력해보세요.
- 내 취향에 꼭 맞는 추천으로 의미 있는 여행을 만들어드립니다.

### AI 엔진 – 믿을 수 있는 기술력

- Tesseract, Kakao Map API, TOUR API, ORS, TMap, GPT-4o 기반
- 영상 분석부터 추천 알고리즘까지, 모든 기능이 **최신 AI 기술**로 구현되어 있습니다.
